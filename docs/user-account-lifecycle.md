# Cycle de vie des comptes utilisateurs

Les comptes ne sont plus supprimés. Un administrateur peut les désactiver ou les
réactiver depuis la liste des utilisateurs.

La désactivation :

- bloque immédiatement les prochaines authentifications ;
- conserve le nom du compte dans les historiques métier ;
- enregistre la date et l’administrateur ayant effectué l’action.

Protections supplémentaires :

- un administrateur ne peut pas désactiver son propre compte ;
- le dernier administrateur actif ne peut pas être désactivé ;
- un seul rôle principal doit être sélectionné par utilisateur.

Une personne quittant l’établissement doit être désactivée, jamais supprimée.
