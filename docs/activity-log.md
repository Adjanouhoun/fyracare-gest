# Journal d’activité

Le journal central est accessible uniquement aux administrateurs depuis le menu
**Application → Journal d’activité**.

Il regroupe en lecture seule les traces métier déjà conservées :

- encaissements et caissiers ;
- annulations et motifs ;
- entrées et sorties manuelles de caisse ;
- clôtures, écarts et retards ;
- changements de statut des rendez-vous ;
- désactivations de comptes.

Il est possible de filtrer le journal par type d’action ou de rechercher un
auteur, un reçu, un rendez-vous ou un motif. Une mention explicite est affichée
quand l’auteur d’une donnée historique n’est pas disponible ; aucune attribution
n’est inventée.
